# 西浦本科专业分流参考 · Major Compass

给西交利物浦大学大一学生用的选专业参考站。

人工智能按校区拆成两个专业：苏州园区的「人工智能（智能系统）」按分数录取（2025-26 官方线 79.5），太仓的「人工智能（产业 AI）」无门槛。

站名「殊途」：一取「殊途同归」——不同专业走的是不同的路；二取「数」——分数。读作 shù tú。

三个页面：

1. **专业查询** — 53 个本科专业按参考录取分从高到低排列，太仓校区的 8 个单独放在最下方（**太仓的专业没有分数门槛**，按热度排序）。每张卡片标注**缩写**（CS、FM、ARCH…）和**火爆程度**（1–5 格），点开看详情：这个专业到底学什么、适合什么样的人、毕业能做什么、申研去向、大一要先修哪些课、参考录取分与区间。
2. **分数测算** — 选一个目标专业，分别填上**平时 / 期中 / 期末**已经出的分（没考完的留空），直接算出剩下的部分**至少要考多少**，并在输入框下方用强调色标出来。
3. **怎么用** — 三步说明、三个前提（分数/占比/不计入的科目）、常见问题、数据来源。

详情页有八段：学什么 / 适合什么样的人（含劝退点）/ 以后能做什么（**鼠标移到标签上，下方显示这个岗位具体在做什么，以及参考年薪**）/ 四年大概会怎么过 / 配图 / 同学院的其它专业 / 进入这个专业（先修与分数口径）/ 页脚免责。首页顶部有一条红色提示，写明分数仅供参考。

列表页顶部还可以切换**排序**：分数从高到低 / 热门程度 / 专业名称，能跟学院筛选、搜索、收藏叠加使用。

支持收藏（★，存在浏览器本地，刷新不丢）。每个专业的详情页有一张**生成式封面**：按专业 id 确定性生成 SVG，配色跟随学院，52 个各不相同。

## 怎么打开

双击 `index.html` 就行，不需要服务器、不需要装任何东西。

> 数据用 `<script>` 直接写在 `js/data.js` 与 `js/content.js` 里，没有 `fetch`，所以在 `file://` 下也能正常跑。

想用本地服务器打开（效果一样）：

```bash

# 然后访问 http://localhost:8000
```

## 测算器是怎么算的

西浦的专业分流**不看大一总 GPA**，只看大一第一学期（Semester 1）的**微积分**（有的专业还要加上**线性代数**）。所以「占比」不是全校统一的，而是**随专业变化**：

| 专业类型 | 计入录取的科目 |
| --- | --- |
| 计算机、电子、数学、建筑等 | 微积分 + 线性代数（各占 50%） |
| 会计、经济、生物、环境等 | 只看微积分（100%） |
| 传播、翻译、设计、影视等 | 不看分数，按志愿与容量 |
| 国际商务 | 不看分数，但要修满第二外语两个阶段 |

每门课内部再按**平时 / 期中 / 期末**拆分（默认 20% / 20% / 60%），两步加权合起来：

```
已得分   = Σ（各部分得分 × 该部分占比 × 该科在录取中的权重）
需要的分 = (目标分 − 已得分) ÷ 还没填的部分的权重之和
```

- **占比可改**：每门课右上角「占比」按钮可以展开，改成你课程大纲上的真实比例，合计不是 100% 会变红提示。
- **目标分可改**：默认填该专业的 2025 参考分，也可以手动改成你查到的实际通知分数。
- EAP 英语和大一选修**不计入**分流，界面上标了「不计入录取」，只影响学位等级。

### 参考分是怎么定的

分数分两类，页面上会标出来：

- **官方（18 个专业）** — 来自《The AY2025-26 Admission Marks of the Starred Programmes》和《23-25 各专业录取分数参考》：EST 89.5 / CST 86 / EE 85.5 / MRS 83.5 / AI 智能系统 79.5 / TE 79.5 / 经金 76 / 应物 76 / 应数 75 / DMT 74.5 / ICS 66 / 经济 66 / 会计 64 / 信管 62 / 金数 61 / 精算 47 / 生统 45 / 生科 44.5。其中 15 个专业还能查到 23-24、24-25 两年的分，详情页会画成「近三年」；这几年波动很大（计算科学 85 → 66、机械电子 76 → 83.5、经济 57 → 66）。
- **参考分（其余专业）** — 官方没公布，按社区流传的口径估算，只能横向比冷热。

**太仓校区的专业不按分数录取**，卡片上直接写「无门槛」。「人工智能」有两处：园区 Intelligent Systems 方向按分数录取（79.5），太仓的 Advanced Industrial AI 无门槛，站里那张卡指太仓方向，详情里有说明。

**它只用来比较专业之间的冷热，不能当承诺。** 真实结果按当年容量和报名情况浮动；如果你是当事人、手上有更准的数，直接改 `js/data.js` 里对应专业的 `score` 与 `past` 即可，页面立刻生效。

## 这一轮新增的六个功能

1. **分数只写有据可查的**：18 个专业显示学校公布的录取分（标「官方」），其余一律写「未公布」，不再给估算数字。排序时官方分的专业排在前面。
2. **专业对比**（导航「对比」）：最多并排 3 个专业，比较录取分、录取口径、大一先修、火爆程度、核心课程、典型出路、参考年薪。选择会存在浏览器里。
3. **按分数找专业**（分数测算页的第二个模式）：填微积分、线代两门分，按 2025-26 分数线分成「稳了 / 能冲 / 够呛 / 学校没公布」四组。
4. **核心课程**：每个专业详情页列出 5 门代表性课程（`js/courses.js`）。
5. **数据来源与口径**：「怎么用」页底部有一张表，逐项写明每个数字从哪来、限制是什么、什么时候核对的。
6. **拼音搜索**：输入 `jisuanji` 或 `jsj` 也能搜到计算机科学与技术（`js/courses.js` 里的 `MAJOR_PY`）。

## 中英切换

导航右侧的 EN / 中文 按钮切换界面语言（会记在浏览器里）：导航、按钮、筛选、排序、表头、章节标题、分数口径等界面文案都有英文版；专业介绍、出路解释等长文内容目前保留中文原文。实现在 js/i18n.js，用的是「文本节点精确匹配替换」+ MutationObserver，不侵入渲染逻辑。

## 必须说清楚的限制

1. **分数线不是官方公布的。** 西浦从不发布专业分流分数线，实际录取按当年容量和报名情况浮动，站里的分数只能用来比较专业之间的冷热，**不能当作承诺**。
2. **考核占比也不是官方公布的。** 官方 Module Catalogue 只写学分、学时、教学目标，不写 assessment 权重，所以默认的「作业 15% / 期中 20% / 期末 65%」是常见结构，**请以你课程大纲（Module Handbook）上的实际比例为准**，站里可以逐门改。
3. **火爆程度是主观标注**（1–5 格），依据是近两年报名热度和参考分，不是官方数据。
4. 参考分是一套估算值，只能横向比较专业之间的冷热，不代表具体年份。
5. 先修课要求以 2025-26 学年的指南为准，学校以后可能会调整。
